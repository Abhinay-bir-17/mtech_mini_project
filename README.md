"# mtech_mini_project"

Dataset used for the project can be found here: https://www.kaggle.com/datasets/saeedseraj/zero-day-android-botnet-detection-using-nn

project report and ppt is also present in this repository.

This project presents the development and evaluation of three neural network models for Android botnet detection, each designed as an enhancement over the baseline model proposed in the original research paper titled ”Zero-day Android Botnet Detection Using Neural Networks.”

The first model focuses on performance optimization techniques such as dropout, batch normalization, and L2 regularization to improve generalization.

The second model explores a deeper neural network architecture through systematic hyperparameter tuning to enhance learning capacity.

The third and final model incorporates feature selection techniques to reduce input dimensionality, leading to improved efficiency and accuracy.

All three models demonstrate high performance and robustness while effectively mitigating the risk of overfitting. Comparative analysis shows that the proposed models outperform the original baseline in key evaluation metrics, highlighting their effectiveness for detecting evolving Android botnets.
